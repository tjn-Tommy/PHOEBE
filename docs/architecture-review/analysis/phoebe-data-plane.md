# Panel report — Data plane & contracts (bus, events, writer, contracts, config, sweep, domain)

## 1. Responsibility map

**`phoebe/core/contracts.py`** is the foundation: `ContractModel` (contracts.py:37-46) is a frozen, `extra="forbid"`, `strict=True`, `validate_default=True` pydantic base for everything crossing a boundary. It also provides `NewType` semantic IDs (contracts.py:50-54), bounded physical scalar aliases (`Nanometer` gt=0 lt=20000, `Dbm` -120..40, contracts.py:57-60), dual-clock `timestamps()` (contracts.py:68-75), and `validate_boundary()` (contracts.py:81-91), which JSON-round-trips (`json.dumps(data, default=str)` → `model_validate_json`) so JSON's structural conversions (list→tuple, ISO→datetime) pass while cross-type coercions stay rejected. Observed call sites: exactly the three documented choke points — `parse_app_config` (core/config.py:128), plugin config at dispatch (core/task_manager.py:204), and capability request entry (core/capability.py:125-126).

**`phoebe/core/events.py`** defines the bus vocabulary. Events subclass `BusEvent` (schema_version, bus-stamped `seq`, optional `task_id`, dual timestamps; events.py:45-50). Six concrete types (`DataPointerEvent`, `ProgressEvent`, `RunStateEvent`, `DeviceHealthEvent`, `ErrorEvent`, `LogEvent`) each carry an `event_type` string Literal; discrimination is by that string, not isinstance — `topic_of()` returns `event.event_type` with a class-name fallback (events.py:133-134), and the UI dispatches on `getattr(event, "event_type", "")` (ui/main_window.py:330). Size discipline is layered: `TracePreview` lists schema-capped at 256 points (events.py:53-57), metrics dicts capped at 32 entries (events.py:74-79, 95-100), log messages at 2000 chars (events.py:115), plus `MAX_EVENT_JSON_BYTES = 64_000` (events.py:25) enforced by the bus. `GatewayEvent` is a discriminated closed union (events.py:120-130).

**`phoebe/core/bus.py`** — `EventBus.publish` is synchronous, loop-thread-only (asserted via `bind_loop` thread id, bus.py:115-118), stamps `seq` via `model_copy` (bus.py:119-120), dev-mode-serializes every event to enforce the 64KB cap (bus.py:121-126), stores the event as the per-topic retained snapshot (bus.py:128), and fans out to per-subscriber bounded `asyncio.Queue`s (default 256, config-tunable via `bus_default_queue_size`, config.py:87). Two drop policies: `DROP_OLDEST` (evict + count in `Subscription.dropped`, bus.py:43-49) and `ERROR` (raise `BusOverflowError`, bus.py:50-53). Late subscribers get the retained event first (bus.py:103-104). `ThrottledEmitter` (bus.py:151-202) is a per-topic trailing-edge throttle with `flush_all()` for run end. Consumers observed: `UiEventBridge` pumps six topics into a `pyqtSignal` (ui/bridge.py:36-48), and `Suspender` subscribes to one health/progress topic (core/task_manager.py:466).

**`phoebe/core/writer.py`** — `RunWriter` owns one run's `artifacts.h5` + `metrics.jsonl`. Producers `await append_array()` onto a bounded queue (default 64, config.py:79); a single writer task drains it, doing blocking I/O via `asyncio.to_thread` and resolving a per-item future with the appended row index (writer.py:151-156, 182-198). Datasets are created growable on axis 0, chunked per row, lzf-compressed (writer.py:215-222); attrs contract models are stored JSON-serialized in a parallel `<dataset>__attrs` string dataset (writer.py:225-236); `h5.flush()` after every append (writer.py:237). `aclose()` sends a sentinel, joins the task, then best-effort compacts metrics to parquet (writer.py:169-179, 252-279). The file also holds `RunManifest`/`MetricRow`/`DataPointer` contracts and `new_run_dir` naming (writer.py:290-294). `TaskManager._execute` is the lifecycle owner: creates writer (task_manager.py:310-315), closes it in `finally` (task_manager.py:360-363), writes `run.json` and baselines via `write_json`.

**`phoebe/core/config.py`** — TOML → `AppConfig` with a discriminated `Connection` union over four transports (config.py:50-53). `InstrumentConfig.options` stays a generic dict (config.py:64) for two-stage validation by controller factories (e.g. `SlmOptions` domain/pattern.py:25-37, `OsaOptions` instruments/yokogawa_aq637x/controller.py:46-54). `parse_app_config` reshapes `[plugins."<id>".bindings]` into `plugin_bindings` (config.py:119-132) and surfaces duplicate roles at startup via `role_map()` (config.py:100-106).

**`phoebe/core/sweep.py`** — `grid_scan()` composes checkpoint + apply + acquire + `writer.append_array` + throttled progress per Cartesian point (sweep.py:31-53). Used by one e2e test (tests/test_e2e_sim.py:119); the shipped plugin (`plugins/tpa_multiplier.py:67-76`) writes its own loop instead.

**`phoebe/domain/*.py`** — a consistent dual-track pattern per instrument family: control-plane `ContractModel`s (scan/trigger/channel configs, metadata) plus data-plane `@dataclass(frozen=True, slots=True)` holders of raw ndarrays (`SpectrumTrace` spectrum.py:73-90, `ScopeWaveform` scope.py:70-79, `AnalogTrace` daq.py:32-45, `WaveformDefinition`/`SequenceDefinition` awg.py:63-156) validated by guard functions or `__post_init__` (pattern.py:40-53, awg.py:71-82). SLM frames are uint16 native quantization, never float radians (pattern.py:40-53).

## 2. Strengths

- **The "no bulk data on the bus" invariant is enforced mechanically at three layers**: schema caps on previews/metrics/logs (events.py:56-57, 74-79, 115), the dev-mode 64KB serialize-and-assert on every publish (bus.py:121-126), and ContractModel's strict schema, which cannot type an ndarray field. This is the platform's best property and must be preserved.
- **Backpressure instead of drops on the data plane.** `append_array` awaits a bounded queue and then the writer's future (writer.py:151-156), so a slow disk throttles the experiment loop rather than losing traces or ballooning RAM — exactly the right asymmetry versus the droppable bus.
- **Explicit drop policy + retained snapshots + bus-stamped monotonic `seq`** (bus.py:43-53, 103-104, 119-120) is structurally the right shape for a snapshot-then-stream remote client later, even though pieces are unfinished (see Issues 4, 5, 11).
- **Thread-ownership asserts** on publish (bus.py:115-118) convert a class of silent cross-thread corruption into immediate failures; `publish_threadsafe` gives the sanctioned escape hatch (bus.py:132-135).
- **`validate_boundary`'s JSON-mode trick** (contracts.py:81-91) elegantly reconciles strict mode with tuple-typed config fields, and it is genuinely applied at all three choke points (config.py:128, task_manager.py:204, capability.py:126) — the discipline claimed by docstrings is real.
- **Provenance is first-class**: `RunManifest` records verbatim config, config hash, app-config hash, git commit/dirty, and per-instrument identity (writer.py:65-77, task_manager.py:375-402); `SlmOptions.settle_ms` landing in the manifest makes timing reproducible (pattern.py:28).
- **Domain dual-track pattern is disciplined and uniform** across five families; the AWG models encode real instrument semantics (64-sample granularity padding awg.py:88-98, marker bit packing awg.py:100-105, sequence referential integrity awg.py:142-156), and `average_traces_dbm` correctly averages in the linear domain (spectrum.py:93-97).
- **Trailing-edge throttling with end-of-run flush** is correctly wired (`ctx.flush_events()` before writer close, task_manager.py:359; `flush_all` bus.py:195-202), so the final progress event survives the throttle window.

## 3. Issues

**I1 — Writer-task death permanently hangs the run; cancel cannot reach it. Severity: Critical.** If `_open_files` raises (disk full, permissions — writer.py:201-204) or `_write_metric` raises (unguarded at writer.py:196, unlike `_write_array`'s try at writer.py:190-194), the writer task exits. Every producer already awaiting a `fut` (writer.py:156) and every future queued behind the failure is never resolved. Cancellation is cooperative-only — `request_cancel` sets a token (task_manager.py:258-267) that fires at checkpoints (task_manager.py:105-116), and a plugin parked inside `await fut` never reaches a checkpoint. The lease heartbeat also lives in `checkpoint` (task_manager.py:107), so leases go stale while the run occupies RUNNING forever; `aclose`'s `await self._queue.put(_CLOSE)` (writer.py:175) can itself block on a full queue with a dead consumer, and it runs in the `finally` *outside* the `asyncio.timeout` that only wraps controller cleanup (task_manager.py:351-356 vs 360-363). Trigger: disk fills during an overnight sweep → unkillable run, no terminal event, UI permanently blocked. No test covers writer failure (tests/test_e2e_sim.py has only happy-path h5 assertions, lines 94, 127).

**I2 — No durability guarantee: no fsync, no SWMR, file unreadable mid-run. Severity: High.** `h5.flush()` per append (writer.py:237) reaches the OS cache only; `metrics.jsonl` is line-buffered with no fsync (writer.py:203-204). On power loss/OS crash, recent appends vanish and — since the file is opened `"w"` with `libver="latest"` but SWMR is never enabled (writer.py:202) — the HDF5 file may be structurally unreadable, not merely truncated (UNCERTAIN in degree: confirming requires a kill test; HDF5 without SWMR is documented as not crash-consistent). Same root cause blocks any live reader (analysis notebook, future web data endpoint) from opening `artifacts.h5` while a run holds it, due to HDF5 file locking — `DataPointerEvent`s are only actionable post-run.

**I3 — Run outcome is never persisted to the run directory. Severity: High.** `run.json` is written once, before RUNNING (task_manager.py:326); terminal state exists only as bus events and log lines. A crashed process leaves a run dir indistinguishable from a completed one except by forensic reading of `experiment.jsonl`; `RunManifest` (writer.py:65-77) has no status/ended_at fields. This silently undermines the provenance story for any downstream cataloguing.

**I4 — Drop observability is claimed but unimplemented. Severity: High.** The comment says drops are "exposed as a health metric" (bus.py:49), and `total_dropped()` exists (bus.py:140-148), but grep shows no production caller anywhere — nothing publishes it as `DeviceHealthEvent`, logs it, or shows it in the UI. A slow UI silently loses `run_state` or `data_pointer` events with zero indication; the operator cannot distinguish a stalled experiment from a saturated subscriber. Silent misbehavior in the observation path.

**I5 — Retained/topic model is per-event-type, not per-entity. Severity: High.** Topics are exactly the six `event_type` strings (events.py:133-134); the retained map keeps one event per topic (bus.py:128). With multiple instruments, `retained("device_health")` holds only the most recently reporting instrument, so a late subscriber's "snapshot" misses every other device; after a run ends, a fresh subscriber receives a stale `progress`/`run_state` from an old `task_id` and must know to filter. This breaks the snapshot-then-stream contract precisely where a reconnecting web client would rely on it, and it forces every consumer to re-implement task/instrument filtering (as `Suspender` implicitly assumes single-metric-source at task_manager.py:469-470).

**I6 — Vendor SCPI mnemonics baked into "domain" contracts. Severity: Medium.** Scope configs use R&S RTO literal spellings — `"NORMal"`, `"CHANnel1"`, `"EXTernanalog"`, `"PDETect"`, `"HRESolution"` (domain/scope.py:24-37) — in what is nominally the vendor-neutral domain layer. A second scope vendor must either parse R&S tokens or fork the config models, defeating the kind/vendor/model registry design.

**I7 — Plugin TOML content other than `bindings` is silently discarded. Severity: Medium.** `parse_app_config` pops the whole `plugins` table and copies only `bindings` (config.py:121-126). `[plugins.foo.defaults]` or a typo'd `bindngs` vanish without error — directly contradicting the module's fail-fast promise (config.py:3-6); the user discovers it as a runtime DI resolution failure. Also mutates the caller's `raw` dict via `pop` (config.py:121).

**I8 — `grid_scan` persists only `y_dbm` + point coordinates; axis and instrument metadata lost. Severity: Medium.** sweep.py:48-50 writes `trace.y_dbm` with `ScanPointMeta(index, point)` — `TraceMeta` (instrument id, scan config, timestamps; spectrum.py:64-70) is dropped, so the wavelength axis of a stored grid-scan trace is only reconstructible by parsing `run.json`'s verbatim plugin config. Compare tpa_multiplier, which at least writes `trace.meta` as attrs (plugins/tpa_multiplier.py:67-68). Additionally `grid_scan` is hard-typed to `SpectrumTrace` (sweep.py:35, 48) despite billing itself as the generic "90% of experiments" primitive (sweep.py:3-5) — it cannot sweep a scope/DAQ acquire without duck-typing `y_dbm`/`preview()`.

**I9 — `GatewayEvent` union is dead code. Severity: Medium.** Defined at events.py:120-130 and referenced nowhere except docs (grep: no code consumer). The stated rule "an event type not registered here cannot leave the process" (events.py:119, 5-6) is not enforced by any code path today; the process boundary it guards does not exist yet, so drift between the union and actual event classes would go unnoticed.

**I10 — `ERROR` drop policy raises into the publisher and truncates fan-out. Severity: Medium (latent).** `_offer` raises `BusOverflowError` synchronously inside `publish`'s subscriber loop (bus.py:50-53, 129-130), so one overflowing internal subscriber aborts e.g. `record.set_state` (task_manager.py:156) mid-broadcast and starves the remaining subscribers of that event. No production subscriber uses ERROR today (only ui/bridge.py:40 and task_manager.py:466, both default DROP_OLDEST), so this is a loaded trap for the first "serious internal subscriber" the docstring invites (bus.py:24).

**I11 — `Subscription.close()` does not wake a blocked consumer. Severity: Medium.** `_iterate` awaits `self._q.get()` unconditionally (bus.py:70-72); `close()` only flips a flag (bus.py:64-65). Calling `unsubscribe` while a consumer awaits leaves that task parked forever. Current consumers dodge it by cancelling the consuming task instead (ui/bridge.py:50-54, task_manager.py:449-456), but the API's obvious usage is a leak.

**I12 — First append freezes dataset shape and dtype. Severity: Medium.** `maxshape=(None, *arr.shape)` and per-row assignment (writer.py:215-224) mean a mid-run change of OSA `points` (legitimate between sweep phases) fails deep inside h5py with a broadcast error relayed through the future — run FAILED with an opaque message, no contract-level check naming the dataset/shape mismatch.

**I13 — Preview decimation can erase narrow peaks. Severity: Low/Medium.** `SpectrumTrace.preview` picks 256 evenly spaced samples (spectrum.py:81-86) — no min/max envelope — so a sub-pixel-width line in a 100k-point trace can disappear from the live plot while the optimizer metric sees it. Confusing operator feedback rather than data loss (full data is in HDF5).

**I14 — Assorted Low items.** (a) `config_hash` isn't canonicalized — dict key order changes the hash (config.py:135-137, model_dump_json preserves insertion order). (b) `instrument_id` uniqueness is never checked; `AppConfig.instrument()` returns the first match (config.py:94-98) while `role_map` checks roles only (config.py:100-106). (c) `MAX_EVENT_JSON_BYTES` compares `len(str)` (characters) not bytes (bus.py:123), and the check is an `assert` — void under `python -O` and in `mode="prod"`; note `mode` defaults to `"dev"` (config.py:88), so every publish pays a full JSON serialization by default. (d) `ThrottledEmitter` uses deprecated `asyncio.get_event_loop()` (bus.py:171, 185). (e) `TracePreview` doesn't require `len(x_nm)==len(y_dbm)` (events.py:56-57). (f) `DataPointerEvent.dataset` is a stringly-typed `"artifacts.h5:/path"` convention built at writer.py:155 that consumers must parse. (g) `WaveformDefinition.markers` is a caller-owned Mapping validated only at construction — mutating the dict afterwards bypasses `__post_init__` (awg.py:69-82). (h) UNCERTAIN: a NaN in `ProgressEvent.metrics` validates in-process but pydantic serializes inf/nan as `null` by default, so it would fail JSON round-trip at a future websocket boundary — confirm with pydantic's `ser_json_inf_nan` default in the pinned version. (i) `new_run_dir` uses second-resolution stamp + 4-char suffix with `mkdir(exist_ok=True)` (writer.py:290-294, task_manager.py:301) — a collision would silently merge two runs.

## 4. Extension pain points

- **New instrument kind:** the domain dual-track pattern scales cleanly, but `TracePreview` is spectrum-shaped and lives in core events (events.py:53-57), and `DataPointerEvent.preview` is typed to it (events.py:65) — a camera frame or scope preview needs core-events surgery plus a `GatewayEvent` union edit. `grid_scan`'s `SpectrumTrace` typing (I8) means every non-OSA kind rewrites the sweep loop.
- **Web (Vue/Tauri) frontend:** the event vocabulary is already JSON-clean and discriminated (genuinely good), but three gaps bite immediately: retained snapshots are per-coarse-topic (I5), so reconnect semantics are wrong beyond one device/one run; `seq` exists but there is no replay buffer to fill gaps after a websocket hiccup; and full-resolution data access mid-run is impossible while the writer holds the HDF5 file (I2). Also the plugin↔controller boundary passes ndarray dataclasses by reference (`acquire_trace → SpectrumTrace`, instruments/protocols.py:39) — fine in-process, but it means the capability layer, not the protocol layer, is the only remotable seam, and today only auxiliary ops (find-peaks, yokogawa controller.py:57-61) go through it.
- **Reconnection / fault recovery:** RunWriter has no reopen/rotate/degrade path — any writer I/O error is terminal and currently hangs rather than fails (I1); there is no persisted run outcome to resume against (I3); the retained-event model gives a restarted UI a partially stale world (I5).
- **New plugin:** the happy path is genuinely small (tpa_multiplier is ~80 lines), but authors must know unwritten rules: attach `trace.meta` as attrs yourself or lose the axis (I8), filter bus events by `task_id` yourself, and never change an array's shape within one dataset (I12).
